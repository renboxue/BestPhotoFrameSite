智伴亲情相框隐私政策

发布日期：2026年9月30日　｜　生效日期：2026年9月30日

我们以本地优先、最小必要为原则处理家庭照片、视频和设备信息。请在使用前阅读本政策。

核心说明：当前版本的家庭照片和视频默认通过局域网在手机与家庭相框之间直接传输并保存在相框设备本地，不作为云相册内容上传到我们的服务器。

一、运营者与适用范围

本应用由北京博学智伴软件开发工作室（个体工商户）开发并运营。本政策适用于“智伴亲情相框”Android 客户端及相关服务。

二、我们处理的信息及用途

1. 家庭照片、视频及媒体信息

当您使用传照片和视频、相册、腾空间等功能时，我们会在获得系统授权后读取您选择或允许访问的照片、视频及必要媒体信息（例如文件名称、媒体类型、大小、时间、URI/路径等），用于展示、筛选、传输、备份状态判断和空间整理。

照片和视频主要在您的手机与家庭相框之间通过局域网传输。当前版本不会把家庭照片和视频作为云相册内容长期上传到我们的服务器。

2. 局域网、Wi-Fi 与附近设备信息

为发现家庭相框、进行设备绑定、局域网传输、热点直连及保持传输状态，我们可能处理网络状态、Wi-Fi 状态、局域网 IP、附近设备连接能力等信息。相关信息主要用于设备间通信，不用于识别您的精确地理位置。

3. 账号、家庭和设备关系信息

如您使用需要登录的家庭管理功能，我们会处理完成认证、维持登录状态、创建/加入家庭、绑定相框所必要的账号标识、家庭关系、设备关系及相关状态信息。

4. 设备和应用基本信息

为保障兼容性、服务稳定、安全、故障诊断和商业权益恢复，我们可能处理设备型号、操作系统版本、应用版本、网络状态、错误日志、设备本地生成或用于商业权益识别的标识等信息。

5. 广告相关信息

免费版本可能使用 DCloud uni-AD 及其广告渠道 SDK 展示广告。仅在符合应用隐私同意条件后，广告链路才按实际配置初始化。广告 SDK 可能为广告投放、统计、归因、反作弊处理设备品牌/型号、系统版本、屏幕信息、应用名称/包名/版本、网络类型、IP 地址、OAID、Android ID 以及广告曝光、点击等交互数据。

当前应用侧广告隐私配置关闭了电话状态、精确位置、安装应用列表、运行应用列表、MAC 地址、传感器等可选敏感采集能力；广告渠道组件的实际处理还受渠道自身规则、设备环境及后台配置约束。详见《第三方 SDK 清单》。

6. 支付与商业权益信息

购买设备级永久去广告时，Pad 端可能通过微信支付二维码完成支付。我们不会获取您的完整银行卡号、支付密码等金融账户敏感信息，仅处理订单号、商品、金额、支付状态、交易结果及设备权益状态等完成核验和权益发放所需的信息。

7. 相机、通知与应用更新

相机仅在您主动进入二维码扫描等功能时使用；通知用于传输状态和必要服务提醒；安装应用包权限仅用于您主动确认的版本更新安装。详细权限用途见《系统权限说明》。

三、第三方 SDK 与共享

为实现广告、支付、二维码识别、图片加载等功能，本应用可能向相应第三方服务提供实现该功能所必需的信息。我们不会出售您的个人信息，也不会将家庭照片和视频提供给广告平台用于广告投放。

第三方 SDK 的名称、用途、信息类型及实际启用说明请见《第三方 SDK 清单》。

四、信息存储

  • 家庭照片和视频主要保存在手机或家庭相框设备本地。
  • 商业权益、订单、账号/家庭关系及服务运行所需的必要数据可能保存在我们的服务器。
  • 当前中国大陆版本不以将用户个人信息向境外提供作为产品功能目的。
  • 我们仅在实现服务目的所必要的期限内保存相关数据，法律法规另有规定的除外。

五、信息安全

我们会采取合理的访问控制、HTTPS 传输保护、最小权限、日志和异常监控等措施保护相关信息。任何网络和存储系统均无法保证绝对安全，对于特别重要的家庭影像，建议您保留额外备份。

六、您的权利

您可以依法查询、更正、复制、删除个人信息，并可撤回相应权限或同意。系统权限可在 Android 设置中关闭；服务器侧账号/家庭关系的注销和删除方式见《账号注销与数据删除说明》。

对于手机和相框设备上的本地照片、视频，您可通过系统相册、本应用管理功能或设备存储自行查看和删除。为避免误删，账号注销不会自动删除本地家庭影像。

七、未成年人保护

本应用主要面向家庭用户，并非专门面向未成年人独立提供服务。未成年人应在监护人指导和同意下使用。家庭照片中可能包含未成年人影像，但我们不会仅因照片中出现未成年人而主动进行身份识别或画像营销。

八、政策更新

我们可能根据产品功能、第三方 SDK、法律法规或监管要求更新本政策。如个人信息处理目的、方式或范围发生重大变化，我们会依法进行显著提示，并在需要时重新征得同意。
