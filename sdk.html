THIRD-PARTY SDK LIST

第三方 SDK 与第三方服务清单

发布日期：2026年9月30日　｜　生效日期：2026年9月30日

当前正式 APK 使用 DCloud uni-AD 官方原生广告组件，并集成二维码、图片加载等必要第三方组件。广告渠道是否实际参与请求由后台配置决定。

一、DCloud uni-AD 原生广告 SDK

提供方：数字天堂（北京）网络技术有限公司（DCloud）
用途：广告拉取、展示、统计、归因、反作弊和广告渠道聚合
可能处理：设备品牌/型号、系统版本、屏幕信息、应用信息、网络类型、IP、OAID、Android ID、广告曝光/点击等交互数据
当前 SDK 版本：5.5.2.0606
隐私政策：uni-AD 原生广告 SDK 隐私政策

二、uni-AD 广告渠道组件

为便于应用上架后按 uni-AD 后台审核结果启用广告渠道，当前 APK 使用 DCloud 官方完整 Android 广告组件。安装包中可能预置而不一定实际请求的渠道包括：

  • 腾讯优量汇
  • 字节跳动穿山甲 / GroMore
  • 快手广告
  • 百度百青藤
  • Sigmob
  • 章鱼广告
  • 泛连广告
  • 华夏乐游 / 优推
  • 以及 DCloud 当前组件和后台支持的倍孜、佳投、旺脉等渠道

实际参与广告请求的渠道由 uni-AD 后台配置、渠道审核状态、设备环境和广告库存共同决定；未启用渠道不会由本应用主动发起商业广告请求。

上述广告渠道通常为广告投放、归因、统计、反作弊和服务稳定处理设备基本信息、应用信息、网络信息、设备标识符及广告交互数据。不同渠道的具体处理以其公开隐私政策和实际启用配置为准。

三、微信支付

用途：设备级永久去广告购买。支付由微信支付服务处理，我们仅处理订单核验、支付结果及权益发放所需的信息，不获取完整银行卡号和支付密码。

四、ZXing 二维码组件

组件：ZXing / zxing-android-embedded
用途：二维码生成或识别、设备配对等扫码功能。仅在用户主动使用相应功能时处理二维码内容或相机画面。

五、Glide 图片加载组件

组件：Glide
用途：在本地界面加载和展示图片资源、管理必要缓存，不独立用于用户画像。

六、AndroidX / Jetpack 等基础组件

应用还使用 AndroidX、Jetpack Compose、Room、DataStore 等 Android 基础开发组件，用于界面、生命周期、本地数据库和本地配置存储。这些组件不作为独立商业数据接收方运营。

七、更新说明

如后续接入 TopOn、其他广告平台或新增新的第三方服务，我们会在实际版本启用前同步更新本清单和隐私政策。
